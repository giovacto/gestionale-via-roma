Documentazione Tecnica Integrazione E-Commerce — Via Roma

1. Architettura di Sistema

  • Backend: Python / Flask
  • Database: SQLite (Predisposto per MySQL)
  • Hosting: PythonAnywhere
  • Autenticazione: Sessione Flask + Guardia `@app.before_request`

2. Modello Dati (Catalogo & Giacenze)

Entità Modello Descrizione e Campi Chiave
Prodotto Padre Articolo Modello generale (id, codice_modello, nome, prezzo_listino, tipologia)
SKU Figlio VarianteArticolo Articolo fisico reale (id, articolo_id, barcode, colore, taglia_numero, giacenza)

3. Endpoints API (Formato JSON)

A. Lettura Singola SKU

GET /api/articolo/<barcode>

B. Verifica Modello

GET /api/check_modello/<codice_modello>

C. Scarico Magazzino

POST /api/vendi

[
  {
    "variante_id": 12,
    "prezzo_finale": 129.00
  }
]

4. Requisiti Integrativi

  1. API Key: Header X-API-KEY per chiamate server-to-server.
  2. Sincronizzazione: Invocazione POST /api/vendi ad ogni ordine e-commerce.
